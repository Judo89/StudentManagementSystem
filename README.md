# Student Management System

A Java console application for managing student records using OOP principles and data structures.

## Features
- Add, remove, search, and display students
- File-based persistence (students saved in `students.txt`)
- Validation to prevent duplicate student IDs
- Clean and modular design

## Technologies
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling

## How to Run
1. Make sure all `.java` files are in the `src/` folder.
2. Compile all files:
   ```bash
   javac src/*.java
